# SPOR – pacing og video (prototype)

Ferdigbygget versjon av SPOR for testing: https://magnustobiassen1904.github.io/langrenn_web/

Alt behandles i nettleseren; GPX-er og videoer lastes ikke opp noe sted.
Frekvens og teknikk er AI-estimater og ikke nødvendigvis riktige.

Inneholder ffmpeg.wasm-kjernen (FFmpeg, GPL-2.0-or-later). Kildekode: https://github.com/ffmpegwasm/ffmpeg.wasm og https://ffmpeg.org/download.html.
Øvrige lisenser: MediaPipe (Apache-2.0), Leaflet (BSD-2-Clause), uPlot (MIT). Kart © OpenStreetMap-bidragsytere.
